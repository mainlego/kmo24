# Настройка интеграции 1С с сайтом

Есть два способа интеграции:
1. **HTTP-сервис** (рекомендуется) - полный контроль над форматом данных
2. **OData** (простой способ) - публикация стандартных справочников

---

# Способ 1: Публикация через OData (простой)

OData позволяет быстро опубликовать справочники без написания кода.

## Шаг 1: Настройка публикации OData

В конфигураторе 1С:
1. Откройте **Администрирование → Публикация на веб-сервере**
2. Перейдите на вкладку **OData**
3. Установите флажок **Публиковать стандартный интерфейс OData**

## Шаг 2: Выбор публикуемых объектов

В том же окне выберите объекты для публикации:
- `Справочник.Номенклатура` (товары)
- `Справочник.ВидыНоменклатуры` или `Справочник.КатегорииНоменклатуры` (категории)
- `РегистрСведений.ЦеныНоменклатуры` (цены)
- `РегистрНакопления.ОстаткиТоваров` (остатки)

## Шаг 3: Проверка

После публикации OData будет доступен по адресу:
```
http://195.208.167.217/kmo_api/odata/standard.odata/
```

Примеры запросов:
```bash
# Получить список товаров
curl -u "Сайт:пароль" "http://195.208.167.217/kmo_api/odata/standard.odata/Catalog_Номенклатура?\$format=json&\$top=10"

# Получить категории
curl -u "Сайт:пароль" "http://195.208.167.217/kmo_api/odata/standard.odata/Catalog_ВидыНоменклатуры?\$format=json"

# Получить цены
curl -u "Сайт:пароль" "http://195.208.167.217/kmo_api/odata/standard.odata/InformationRegister_ЦеныНоменклатуры?\$format=json"
```

## Имена сущностей OData

| Тип объекта | Префикс | Пример |
|-------------|---------|--------|
| Справочник | `Catalog_` | `Catalog_Номенклатура` |
| Документ | `Document_` | `Document_ЗаказПокупателя` |
| Регистр сведений | `InformationRegister_` | `InformationRegister_ЦеныНоменклатуры` |
| Регистр накопления | `AccumulationRegister_` | `AccumulationRegister_ОстаткиТоваров` |

# Способ 2: HTTP-сервис (полный контроль)

## Шаг 1: Создание HTTP-сервиса

В конфигураторе 1С:
1. Откройте конфигурацию
2. Добавьте новый объект: **Общие → HTTP-сервисы → Добавить**
3. Имя: `WebAPI`
4. Корневой URL: `api`

## Шаг 2: Добавление шаблонов URL

Добавьте следующие шаблоны URL в HTTP-сервис:

| Шаблон | Метод | Имя метода |
|--------|-------|------------|
| `/ping` | GET | `Ping` |
| `/products` | GET | `GetProducts` |
| `/products/{id}` | GET | `GetProduct` |
| `/categories` | GET | `GetCategories` |
| `/stock` | GET | `GetStock` |
| `/orders` | POST | `CreateOrder` |
| `/orders/{id}` | GET | `GetOrder` |

## Шаг 4: Публикация HTTP-сервиса

1. В конфигураторе: **Администрирование → Публикация на веб-сервере**
2. Или через файл `default.vrd`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<point xmlns="http://v8.1c.ru/8.2/virtual-resource-system"
       xmlns:xs="http://www.w3.org/2001/XMLSchema"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       base="/kmo_api"
       ib="Srvr=&quot;localhost&quot;;Ref=&quot;kmo&quot;;">
    <httpServices publishExtensionsByDefault="false">
        <service name="WebAPI"
                 rootUrl="api"
                 enable="true"
                 reuseSessions="autouse"
                 sessionMaxAge="20"
                 poolSize="10"
                 poolTimeout="5"/>
    </httpServices>
</point>
```

## Шаг 5: Настройка пользователя

1. Создайте пользователя `Сайт` в 1С
2. Назначьте ему роль с правами на чтение справочников и создание заказов
3. Установите пароль

## Важные замечания

1. **Названия объектов** в коде (Номенклатура, ВидыНоменклатуры, ЦеныНоменклатуры и т.д.) нужно заменить на реальные названия объектов в вашей конфигурации 1С.

2. **Регистры** остатков и цен могут отличаться в зависимости от конфигурации (УТ, УНФ, БП и т.д.).

3. **Права доступа** - убедитесь, что пользователь имеет достаточные права на чтение данных.

4. **Кодировка** - все строки передаются в UTF-8.
