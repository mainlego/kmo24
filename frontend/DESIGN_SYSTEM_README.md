Компоненты из `components/base/` **не используются** в проекте. Можно безопасно удалить:

```bash
cd frontend
rm -rf components/base/
```

Это удалит 7 неиспользуемых файлов и оставит только актуальные компоненты в `components/common/`.

## 🎨 Быстрый старт

### Использование цветов:

```scss
// SCSS
.button {
  background: $primary;      // ✅
  color: $white;             // ✅
  border: 1px solid $error;  // ✅
}
```

```html
<!-- Tailwind -->
<div class="bg-primary text-white border border-error">
```

### Использование компонентов:

```vue
<template>
  <BaseButton variant="primary" size="md">
    Купить
  </BaseButton>

  <BaseCard variant="elevated">
    <p>Карточка с тенью</p>
  </BaseCard>

  <BaseInput
    v-model="name"
    label="Имя"
    placeholder="Введите имя"
  />
</template>
```

### Использование миксинов:

```scss
@use '~/assets/scss/mixins' as *;

.my-component {
  @include container;           // Контейнер с max-width
  @include card-elevated;       // Карточка с тенью
  @include hover-lift(-8px);    // Подъем при hover
  @include skeleton-loader;     // Skeleton анимация
}
```

### Использование анимаций:

```html
<!-- Готовые классы -->
<div class="animate-fade-in">
<div class="animate-pulse">
<div class="animate-shimmer">
```

```scss
// Или напрямую
.element {
  animation: fadeInUp 0.5s ease-out;
}
```

## 🔍 Проблемы и их решения

### Найденные проблемы:

1. ✅ **Дублирование компонентов** - `components/base/` vs `components/common/`
   - **Решение:** Удалить `components/base/` (не используется)

2. ⚠️ **250+ хардкод цветов** - `#3b82f6` вместо `$info`
   - **Решение:** Заменить на переменные (см. [MIGRATION_PLAN.md](MIGRATION_PLAN.md))

3. ⚠️ **Несистемные отступы** - `padding: 13px`, `margin: 5px`
   - **Решение:** Использовать `$spacing-*` переменные

4. ⚠️ **Дублирующиеся анимации** - локальные @keyframes в компонентах
   - **Решение:** Использовать из `_animations.scss`

### Как избежать в будущем:

1. **Всегда используйте переменные** - никаких хардкод цветов
2. **Проверяйте миксины** - прежде чем писать свои стили
3. **Используйте готовые анимации** - из `_animations.scss`
4. **Читайте документацию** - [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md)

## 🚀 Преимущества системы

### Для разработчиков:

1. **Быстрая разработка** - готовые компоненты и миксины
2. **Консистентность** - все используют одни переменные
3. **Легко менять** - изменить цвет в одном месте
4. **Хорошая документация** - примеры и объяснения
5. **TypeScript поддержка** - типизированный Tailwind конфиг

### Для проекта:

1. **Единый стиль** - нет разных оттенков одного цвета
2. **Меньше кода** - переиспользование вместо дублирования
3. **Лучше производительность** - меньше CSS
4. **Легче поддерживать** - централизованные стили
5. **Проще онбординг** - новые разработчики быстро разберутся
